# Классы в C#: 5 заданий

Решение пяти заданий по теме «Классы». Весь код в одном файле: [`ConsoleApp121/Program.cs`](ConsoleApp121/Program.cs).

## Задания

**1. Книга.** Класс `Book` с полями `Title`, `Author`, `Year` и методом `PrintInfo()`, который выводит информацию о книге. Создаются несколько книг, и для каждой вызывается метод.

**2. Прямоугольник.** Класс `Rectangle` с полями `Width` и `Height` и методами `CalculateArea()` (площадь) и `CalculatePerimeter()` (периметр).

**3. Студент.** Класс `Student` с полями `Name`, `Age`, `Grade` (от 1 до 5) и методом `IsExcellent()`, который возвращает `true`, если оценка равна 5. Для нескольких студентов проверяется, кто из них отличник.

**4. Счётчик.** Класс `Counter` с приватным полем `count = 0` и методами `Increment()`, `Decrement()`, `GetCount()`.

**5. Кошелёк.** Класс `Wallet` с полем `balance = 0` и методами `AddMoney(int amount)`, `SpendMoney(int amount)` (тратит, только если хватает средств) и `GetBalance()`.

## Как запустить

**Visual Studio:** создайте консольное приложение, вставьте содержимое `Program.cs` вместо стандартного кода и нажмите F5.

**Командная строка** (нужен .NET SDK 8):

```
cd ConsoleApp121
dotnet run
```
